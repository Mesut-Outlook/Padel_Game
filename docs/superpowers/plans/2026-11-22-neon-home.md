# Neon HOME Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace HOME with the approved "Pick your legend" neon screen and carry each player's racket colour into Play now.

**Architecture:** A new `src/homehero.js` owns the lanes / cards (markup, pick, scroll). `home.js` composes it and keeps the
online parts behind `callbacks.online`. Three small pure helpers in existing modules cover colour, saving and routing.

**Tech Stack:** plain ES modules, CSS in `index.html`, node:test, pre-rendered WebP. No new dependency.

**Spec:** `docs/superpowers/specs/2026-11-22-neon-home-design.md` · look: `…-neon-home-mockup.html` next to it (local only).

## Global Constraints
- Work in a git worktree on branch `neon-home`: Antigravity may edit the main tree. Never touch or commit `tools/home-preview.html`.
- `data/characters.json` is never reordered. Shared modules stay free of DOM / three imports.
- No live 3D, blur or CSS filter on HOME; no request to another host; no new data flow.
- Every new text goes through `t()` / `N_()` into all 7 locale tables, then `node tools/extract-keys.js`.
- Touch targets at least 44 px; reduced motion respected; names keep at least 3:1 contrast.
- `npm test` passes before each commit. Push / merge only after the security audit and the user's look.

## Review Focus
1. Hiding HOME or rotating resets `scrollLeft`: the saved pick must not become the first player. (Task 3)
2. PLAY NOW tapped while the cards still glide: play the centred player, not the previous one. (Task 3)
3. Storage blocked: picking and playing still work. (Task 1)
4. An old save points at an archived player: an active lane opens. (Task 3)
5. Long de / pt labels on 360x640 and 844x390: no overlap, nothing off screen. (Task 4)

**Produces:**

- `patchPicks(patch, storage, limits) -> void`: `loadPicks` + patch + `savePicks`.
- `playRoute({ url, code, enter, invite }) -> 'ai' | 'online'`: `'ai'` only with no url, code, enter or invite.
